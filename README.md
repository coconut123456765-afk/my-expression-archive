## 화면

### 홈
- **최애 스포트라이트** — 아나스타샤의 대표 일러스트 4점을 6초마다 넘기는 와이드 히어로 카드(점을 눌러 고정).
- **작품 탭** — 전체 / 신데렐라 걸즈 / 림버스 컴퍼니 / 블루 아카이브 / 니케. 탭마다 컷 수 표시.
- **캐릭터 카드** — 모바일 2열, 데스크톱 4열. 카드마다 블러 백드롭 + 얼굴 중심 크롭 + 총 컷수 배지.
- **검색** — 이름 · 영문명 · 작품 · 표정 · 태그로 검색 (`수영복`, `림버스`, `눈감음` …).

### 스튜디오 (캐릭터별 뷰어)
- **큰 스테이지** — 원본 비율을 지키는 `전체`와, 세로 전신은 얼굴·상반신으로 붙는 `얼굴` 보기. 가로 일러스트는 `얼굴`에서 얼굴 쪽으로 1.3배 확대.
- **하단 컨트롤 바** — 배경 4종(투명 체크 · 화이트 · 크로마키 그린 · 딥 네이비) · 전체/얼굴 · 줌 `−` `+` `↺` · 자동재생 · PNG 저장 · PNG 복사 · 원본 링크.
- **필터 칩 두 줄** — `폼`(각성/미각성/푸치/사인, 기본/기사/혈귀/산초 …, 인격 일러스트/인격 프로필/E.G.O, 정월/드레스/전신/메모리얼, 표정 · 스타 …)과 `감정`(미소·웃음·차분·놀람·삐침·찡그림·울먹 …)을 분리. 칩마다 컷 수가 붙습니다.
- **썸네일 그리드** — 모바일 3열 / 데스크톱 4열, `loading="lazy"` + 320×400 경량 썸네일(WebP)로 빠르게 뜹니다.
- **다중 선택 → ZIP** — 썸네일 오른쪽 위 동그라미를 눌러 여러 컷을 고르면 하단에 선택 바가 뜨고, **ZIP 저장**으로 한 번에 받습니다(무압축 ZIP, 순수 JS). 원본이 WebP 여도 **PNG 로 변환해** 담습니다.
- **모바일 조작** — 스테이지에서 좌우 스와이프, 확대 상태에서 드래그 이동, 더블탭 2배.
- **키보드(PC)** — `←` `→` 이전/다음, `+` `-` `0` 확대/축소/초기화, `F` 전체, `G` 얼굴, `Esc` 닫기.

## 열어 보기

### 1) 그냥 웹에서
https://coconut123456765-afk.github.io/my-expression-archive/

### 2) 로컬에서
```bash
cd my-expression-archive
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
`index.html` 을 더블클릭해도 그림은 다 보이지만, `file://` 에서는 브라우저 보안 규칙 때문에
**PNG 저장(다른 이름으로 저장) · 클립보드 복사 · ZIP** 이 제한될 수 있습니다. 로컬 서버나 라이브 주소를 쓰세요.

## 파일 구조

```
index.html            화면 뼈대 (홈 + 스튜디오 + 모달)
styles.css            v3 디자인 (모바일 우선, 다크 갤러리) — v4에서도 그대로
app.js                라우팅·필터·스테이지·저장/복사/ZIP
data/characters.json  캐릭터·컷 데이터 (원본)
data/characters.js    위 JSON 을 window.ARCHIVE_DATA 로 감싼 파일 (페이지가 읽는 것)
assets/{캐릭터}/       원본 WebP q90 (투명 채널 유지)
assets/thumbs/        4:5 얼굴 중심 썸네일 (WebP 320×400)
tools/shoot.py        헤드리스 Chromium 검증 + 스크린샷
SOURCES.md            출처와 다시 받는 방법
```

### 컷 추가하기
1. 이미지를 `assets/{캐릭터id}/NN-이름.png` 로 넣고, 같은 이름의 썸네일을 `assets/thumbs/{캐릭터id}/NN-이름.webp` 로 만듭니다(4:5 크롭, 폭 320).
2. `data/characters.json` 의 해당 캐릭터 `items` 에 컷을 추가합니다.
   ```json
   {
     "id": "anya-33", "file": "assets/anya/33-new.png", "thumb": "assets/thumbs/anya/33-new.webp",
     "title": "새 카드", "type": "일러스트", "form": "각성 일러스트", "emotion": "미소",
     "outfit": "드레스", "tags": ["봄", "벚꽃"], "w": 1280, "h": 824, "focus": 0.42,
     "source": "https://starlight.kirara.ca/card/200527", "sourceLabel": "Starlight Kirara · card 200527"
   }
   ```
   - `form` · `emotion` 값이 그대로 필터 칩이 됩니다.
   - `focus` 는 세로 전신 이미지에서 얼굴 위치(0 = 맨 위, 1 = 맨 아래)입니다. 썸네일 크롭과 `얼굴` 보기가 이 값을 씁니다.
3. `data/characters.js` 를 다시 만듭니다.
   ```bash
   python3 - <<'PY'
   import json
   d = json.load(open("data/characters.json", encoding="utf-8"))
   open("data/characters.js","w",encoding="utf-8").write(
       "window.ARCHIVE_DATA = " + json.dumps(d, ensure_ascii=False, indent=1) + ";\n")
   PY
   ```
