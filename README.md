# 나만의 표정 아카이브 — My Expression Archive

최애 1명 + 서브 3명, **4개 작품**의 실제 표정·스탠딩·일러스트 **22컷**을 모은 개인 아카이브 웹사이트입니다.
외부 CDN·라이브러리 없이 `index.html` 하나를 열면 바로 동작합니다.

**v2 (2026-11-19)** — 서로 다른 이미지 비율(가로 일러스트 1280×824, 정사각형 400×400, 세로 전신 632×1876·447×909)에서 생기던 **잘림·빈 여백**을 프레임 단위로 정리했습니다. 자세한 내용은 아래 [프레임 처리 방식](#프레임-처리-방식-v2)을 참고하세요.

| 캐릭터 | 작품 | 컷 | 이미지 종류 |
| --- | --- | --- | --- |
| ★ 아나스타샤 (최애) | 아이돌마스터 신데렐라 걸즈 | 6 | 카드 일러스트 1280×824 |
| 돈키호테 | 림버스 컴퍼니 | 7 | 투명 스탠딩/표정 632×1876 |
| 리쿠하치마 아루 | 블루 아카이브 | 6 | 얼굴 표정 400×400 (투명) |
| 아니스 | 승리의 여신: 니케 | 3 | 투명 전신 스탠딩 |

## 실행 방법

### 1) 그냥 더블클릭

`index.html` 을 더블클릭하면 바로 열립니다. 데이터(`data/characters.js`)와 이미지 사본
(`data/assets-embed.js`)이 함께 들어 있어서, 서버 없이도 **PNG 저장 · PNG 복사 · 선택 ZIP** 이
모두 동작합니다.

### 2) 로컬 서버 (원본 PNG 바이트 그대로 저장하고 싶을 때)

```bash
cd my-expression-archive
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

- 더블클릭 모드에서는 저장할 때 캔버스로 PNG를 다시 인코딩합니다(화면은 같고 용량은 조금 큽니다).
- 로컬 서버로 열면 `assets/` 의 **원본 PNG 파일을 그대로** 저장하고 ZIP으로 묶습니다.
- 브라우저가 클립보드 복사를 막는 경우에도 로컬 서버 쪽이 확실합니다.

## 기능

- **최애 스포트라이트** — 아나스타샤를 상단 배너에서 6초마다 자동으로 넘겨 보여 줍니다(점 클릭으로 이동).
- **작품 탭 필터** — 전체 / 신데렐라 걸즈 / 림버스 컴퍼니 / 블루 아카이브 / 니케.
- **캐릭터 검색** — 이름·영문명·작품·태그로 검색(예: `림버스`, `수영복`, `차분`).
- **표정 인스펙터**
  - **전체 / 얼굴 보기 전환** — 원본 비율 그대로 보는 `전체(Fit)`, 전신 캐릭터의 얼굴·상반신을 크게 보는 `얼굴(Face)`
  - 스테이지 배경 4종: 투명 체크무늬 / 순백 / 크로마키 그린(`#00FF00`) / 딥 네이비
  - 확대·축소 `−` `+` `↺`, 최대 400%, 확대 상태에서 **드래그로 이동**, 더블클릭으로 2배/초기화
  - 이전/다음 `←` `→` (키보드 방향키 지원, 끝에서 순환)
  - **자동재생 ▶** — 2.6초마다 다음 컷
  - **종류/감정/의상 태그 필터** + 썸네일 그리드
  - **PNG 저장**(원클릭), **PNG 복사**(클립보드), **선택 ZIP**(여러 컷을 한 번에)
  - 컷마다 원본 아카이브 링크 표시, 캐릭터별 출처·저작권 표기
- **반응형** — PC 2단 레이아웃, 모바일 1단(390px 기준 확인).

### 프레임 처리 방식 (v2)

이미지 비율에 따라 프레임 처리가 자동으로 달라집니다.

| 위치 | 처리 |
| --- | --- |
| 캐릭터 카드 · 스포트라이트 · 썸네일 | 같은 이미지를 확대·블러(`blur(18px) brightness(0.55)`)한 **백드롭 레이어**로 빈 여백을 채우고, 전경은 원본 비율을 지키는 `object-fit: contain`(가로·정사각형) 또는 얼굴 중심 크롭(세로 전신)으로 배치 |
| 세로 전신 (돈키호테·아니스) | 캐릭터별 **얼굴 위치(`focus`) 값**을 데이터에 두고, 프레임 비율에 맞춰 `object-position` 을 계산해 머리·얼굴이 잘리지 않게 보여 줍니다 |
| 인스펙터 스테이지 | `전체` = 원본 비율 전체 맞춤(잘림 없음), `얼굴` = 상반신 포커스로 화면을 채움 |

`focus` 는 `data/characters.json` 의 캐릭터 항목에서 조정할 수 있습니다(0 = 이미지 맨 위, 1 = 맨 아래).

### 키보드

| 키 | 동작 |
| --- | --- |
| `←` `→` | 이전 / 다음 컷 |
| `+` `-` | 확대 / 축소 |
| `0` | 확대·위치 초기화 |
| `F` / `G` | 전체 보기 / 얼굴 보기 |
| `Esc` | 안내 창 닫기 |

## 파일 구조

```
my-expression-archive/
├─ index.html            화면 구조
├─ styles.css            다크/네이비 테마, 반응형
├─ app.js                필터·인스펙터·PNG 저장/복사·ZIP 빌더
├─ data/
│  ├─ characters.json    캐릭터·컷 데이터(원본, 편집용)
│  ├─ characters.js      위 JSON을 window.ARCHIVE_DATA 로 감싼 파일(사이트가 읽는 것)
│  └─ assets-embed.js    내장 이미지 사본(WebP data URL) — file:// 저장/복사/ZIP용
├─ assets/
│  ├─ anya/  (6)  아나스타샤
│  ├─ don/   (7)  돈키호테
│  ├─ aru/   (6)  아루
│  └─ anis/  (3)  아니스
├─ tools/build-embed.py  assets-embed.js 재생성 스크립트
├─ tools/shoot.py        Chromium(헤드리스) 검증·스크린샷 스크립트
├─ SOURCES.md            캐릭터별 대량 에셋 확보 경로 + 확장 가이드
└─ README.md             이 문서
```

## 컷 추가하기

1. 이미지를 `assets/{캐릭터id}/` 에 넣습니다.
2. `data/characters.json` 에 컷을 추가합니다(`type`/`emotion`/`outfit`/`tags`/`source` 포함).
3. `data/characters.js` 를 JSON으로 다시 만듭니다 — 자세한 명령은 `SOURCES.md` 6장.
4. `python3 tools/build-embed.py` 로 내장 사본을 갱신합니다.
5. `index.html` 새로고침.

## ZIP 내보내기 구현 메모

`선택 ZIP` 은 라이브러리 없이 **무압축(STORE) ZIP** 을 직접 만듭니다
(`app.js` 의 `buildZipBlob` · `crc32` · `dosDateTime`). 로컬 헤더·중앙 디렉터리·EOCD를
직접 쓰고, 한글 파일명을 위해 UTF-8 플래그(0x0800)를 켭니다. ZIP 안에는 이미지와 함께
`CREDITS.txt`(출처·저작권 요약)가 들어갑니다.

## 알려진 제약

- 브라우저가 클립보드 이미지 쓰기를 지원하지 않거나 권한을 막으면 안내 창이 뜹니다(그때는 PNG 저장 사용).
- 더블클릭 모드의 PNG는 캔버스 재인코딩 결과라 원본 PNG와 바이트가 다르고 용량이 조금 큽니다.
- `assets-embed.js` 는 22컷 기준 약 4.7MB입니다. 컷을 수백 장으로 늘리면 이 파일이 커지므로,
  그때는 로컬 서버로 여는 방식을 권장합니다(내장 사본이 없는 이미지는 자동으로 `assets/` 경로 사용).
